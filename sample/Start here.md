# Start here

Folio opens a folder of Markdown files. This is a sample workspace: change anything here, or open a folder of your own from Home.

## Write the way you want

You’re in **Preview**, an editable page. Click anywhere in the text to write. Type `/` on an empty line for a list, heading, or quote.

- **Editor** shows the original Markdown.
- **Split** puts Markdown and its preview side by side.
- **Preview** is for writing without the syntax in your way.
