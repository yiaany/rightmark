# Product artwork

`workspace.webp` is an unretouched capture of rightmark’s Dark theme with the bundled **Studio refresh** sample open. The running app and bundled sample are the source; the only processing is WebP compression.

The canonical app icon is [`public/rightmark.svg`](../../public/rightmark.svg). Generate matching bundle icons with the Tauri icon command and retain `32x32.png` and `icon.icns` under `src-tauri/icons/`.
