**Taking notes shouldn’t be a second job.** Capture a passing thought, write in plain Markdown, and find it again without building a system around it.

This is the first **unified rightmark preview for Mac and Windows**. Both installers come from the same source commit. The Windows build includes the compact title bar, keyboard shortcuts with Ctrl, and an edge-to-edge writing view when the sidebar is hidden.

| Platform | Installer |

| **Windows 11 · x64** | [Download the setup executable](https://github.com/yiaany/rightmark/releases/download/v0.1.1/rightmark_0.1.1_x64-setup.exe) |

Use [`SHA256SUMS.txt`](https://github.com/yiaany/rightmark/releases/download/v0.1.1/SHA256SUMS.txt) to verify either download. Intel Mac and Windows ARM64 installers are not included. Windows setup may connect to the internet if it needs to install Edge WebView2.

## Preview status

The Mac app is not Developer ID–signed or notarized, and the Windows installer is unsigned. Gatekeeper or SmartScreen may warn. Use a copy of important notes while testing. The editor does not require an account, and notes stay in the folder you open.
