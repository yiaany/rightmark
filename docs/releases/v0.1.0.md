# rightmark 0.1.0 — Preview

The first preview of rightmark: a quiet Mac workspace for notes that stay in your own Markdown files.

- Capture from anywhere on your Mac, then sort notes in Inbox. Keep a separate daily journal in Today.
- Write visually or work directly in Markdown. Follow backlinks, jump through an outline, and paste screenshots into the note you’re writing.
- Manage the checkboxes already in your notes, with due dates and a direct jump to the source.
- Resume open tabs after relaunch, recover unsaved drafts, compare conflicting edits, or restore a previous version.

## Download

**Apple silicon · macOS 13 or later.** Download `rightmark_0.1.0_aarch64.dmg`, then drag rightmark to Applications. The SHA-256 checksum is attached separately.

This preview is not signed with Developer ID or notarized, so macOS may block it on first launch. Use a copy of important notes while testing. Intel and Windows builds are not part of this preview.

Start with the sample workspace or [open your own Markdown folder](https://github.com/yiaany/rightmark/blob/main/docs/WORKSPACE.md).
